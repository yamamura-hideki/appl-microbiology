このゲームについて

土1gの中には、およそ100万もの放線菌がすんでいます。特に多いのは、落ち葉などが分解されてできた腐植を含む層です。放線菌は、抗生物質など多くの「クスリの種」を生み出してきた微生物です。

ところが、ふつうの方法で土から分離すると、その9割以上がストレプトマイセス属。それ以外の希少放線菌は、見つけるだけでもひと苦労です。

当研究室では、腐植酸を使った分離培地や、泳ぐ胞子の性質を利用した分離法を開発し、まだ誰も見ていない放線菌を探しています。

研究をもっと知る

  • 放線菌に関する研究
  • 放線菌の新しい分離培地（HV寒天）
  • 泳ぐ放線菌の高度選択分離法
  • 配属・進学を考えている方へ

※「深く掘るほど希少な菌が出やすい」などのルールは、ゲームとして遊びやすくするための設定です。
