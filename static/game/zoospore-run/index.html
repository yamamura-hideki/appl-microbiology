このゲームについて

放線菌のなかには、胞子が鞭毛で水の中を泳ぐ運動性放線菌がいます。乾かした土に液体を注ぐと、胞子のうから泳ぐ胞子（遊走子）が泳ぎ出します。

遊走子は、γ-コリジンなどの化学物質に引き寄せられて泳ぐ性質（走化性）をもっています。当研究室では、この性質を利用して、土の中の多くの微生物から運動性放線菌だけを選んで集める分離法を開発しました。

ゲームでは、あなたが遊走子になって、においの濃い方へ泳いで捕集口を目指します。

研究をもっと知る

  • 泳ぐ放線菌の高度選択分離法
  • 放線菌に関する研究

  • 配属・進学を考えている方へ
